# Параметры подключения к PostgreSQL

## База данных

- **Имя базы данных:** `vikingi_analytics`
- **Хост:** `localhost` (на сервере 3) или IP-адрес сервера 3
- **Порт:** `5432` (по умолчанию)

## Пользователи

### analytics_user
- **Назначение:** Система аналитики звонков, Telegram-бот
- **Права:** Полные права (CREATE, INSERT, UPDATE, DELETE, SELECT)
- **Использование:** 
  - Создание таблиц для аналитики
  - Запись данных о звонках
  - Работа Telegram-бота

### ics_user
- **Назначение:** Подключение из 1С Альфа 6.0
- **Права:** Только чтение (SELECT)
- **Использование:**
  - Чтение данных аналитики из 1С
  - Просмотр статистики звонков

## Подключение из командной строки

### От пользователя analytics_user:
```bash
psql -U analytics_user -d vikingi_analytics
```

### От пользователя ics_user:
```bash
psql -U ics_user -d vikingi_analytics
```

## Подключение из 1С Альфа 6.0

### Параметры подключения:
- **Тип СУБД:** PostgreSQL
- **Сервер:** IP-адрес сервера 3 (например, `192.168.1.100`)
- **Порт:** `5432`
- **База данных:** `vikingi_analytics`
- **Пользователь:** `ics_user`
- **Пароль:** [пароль, указанный при создании]

### Настройка в 1С:
1. Администрирование → Подключение к внешним источникам данных
2. Тип: PostgreSQL
3. Ввести параметры подключения
4. Тест подключения

## Настройка файрвола (для доступа с сервера 1С)

Если сервер 1С находится на другом компьютере, нужно открыть порт 5432:

```bash
# Разрешить доступ только с IP сервера 1С
sudo ufw allow from <IP_сервера_1С> to any port 5432

# Или разрешить доступ со всей сети (менее безопасно)
sudo ufw allow 5432/tcp
```

## Настройка PostgreSQL для удаленного доступа

Если нужно подключение с другого сервера, отредактируйте файл:

```bash
sudo nano /etc/postgresql/16/main/postgresql.conf
```

Найдите строку:
```
#listen_addresses = 'localhost'
```

Измените на:
```
listen_addresses = '*'  # или конкретный IP
```

Затем отредактируйте файл `pg_hba.conf`:
```bash
sudo nano /etc/postgresql/16/main/pg_hba.conf
```

Добавьте строку для доступа с сервера 1С:
```
host    vikingi_analytics    ics_user    <IP_сервера_1С>/32    md5
```

Перезапустите PostgreSQL:
```bash
sudo systemctl restart postgresql
```

## Проверка подключения

### С локального сервера:
```bash
psql -U analytics_user -d vikingi_analytics -c "SELECT version();"
```

### С удаленного сервера (если настроен доступ):
```bash
psql -h <IP_сервера_3> -U ics_user -d vikingi_analytics -c "SELECT version();"
```

## Безопасность

⚠️ **Важно:**
- Используйте сложные пароли
- Ограничьте доступ по IP (через файрвол и pg_hba.conf)
- Используйте SSL-соединение для удаленных подключений (рекомендуется)
- Регулярно обновляйте PostgreSQL
