# Принятие условий использования модели

Для доступа к модели pyannote/speaker-diarization-community-1 нужно:

1. Откройте в браузере: https://hf.co/pyannote/speaker-diarization-community-1

2. Войдите в аккаунт Roman31052008 (если не авторизованы)

3. Нажмите кнопку "Agree and access repository" (Согласиться и получить доступ)

4. После этого модель будет доступна для загрузки

Токен задавайте локально через переменную окружения `HF_TOKEN` (значение не хранить в файле).

После принятия условий запустите анализ снова.
