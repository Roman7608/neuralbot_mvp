## 📍 Развертывание PostgreSQL

### Где будет развернута база данных

**PostgreSQL будет установлена на локальном сервере №3**, где находится:
- Проект Vikingi (голосовой бот, Telegram-бот)
- Аудиозаписи звонков
- Система аналитики звонков

**Архитектура:**
```
Сервер 1 (локальный): 1С Альфа 6.0
    │
    │ (подключение к PostgreSQL)
    │
    ▼
Сервер 3 (локальный): PostgreSQL + Проект + Аудиозаписи
    │
    │ (получение записей)
    │
    ▼
Сервер 2 (облачный): Asterisk
```

**Преимущества:**
- Единый источник данных
- Быстрый доступ к данным
- Упрощенная синхронизация
- Централизованное управление

**Требования к серверу 3:**
- Минимум 16 ГБ RAM (рекомендуется 32 ГБ)
- SSD для БД (рекомендуется)
- Достаточное место на диске для аудиозаписей (14 дней хранения)

## 📋 Регистрация Telegram-канала в России

### Требуется ли регистрация в госорганах?

**Ответ: НЕТ, регистрация не требуется.**

**Обоснование:**
1. **Telegram-каналы** - это публичные каналы внутри мессенджера Telegram
2. Они не являются СМИ (средствами массовой информации) в юридическом смысле
3. Регистрация в Роскомнадзоре требуется только для:
   - Официальных СМИ (газеты, журналы, телеканалы)
   - Новостных агрегаторов с определенной аудиторией
   - Ресурсов, распространяющих новости как основной контент

**Что нужно сделать:**
1. Создать канал в Telegram (внутри приложения)
2. Добавить бота как администратора
3. Указать ID канала в конфигурации
4. Начать публиковать контент

**Важные моменты:**
- Канал должен соответствовать правилам Telegram
- Контент должен соответствовать законодательству РФ
- Если канал будет использоваться для рекламы, нужно соблюдать закон "О рекламе"
- Если собираются персональные данные подписчиков, нужно соблюдать 152-ФЗ

**Для дилерского центра:**
- Канал для новостей, акций и справочной информации **не требует регистрации**
- Это информационный канал компании, а не СМИ
