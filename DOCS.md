# Документация проекта Vikingi

Краткий указатель основных документов для разработчиков и Cursor.

---

## Развёртывание и архитектура

- **`DEPLOYMENT_GUIDE.md`** — развёртывание: серверы, БД, Asterisk, SFTP, домены.
- **`PROJECT_STATUS_SUMMARY.md`** — статус проекта, что готово и что в доработке.
- **`PROJECT_STATUS.md`** — детальное описание архитектуры (Asterisk, RTP, бот, 1С).

---

## Спецификации и ТЗ

- **`TZ_asterisk_fallback_and_transfer.md`** (в корне проекта) — **ТЗ для провайдера (Asterisk)** и реализация на боте:
  - маршрутизация звонка на номер администратора при недоступности/занятости/падении бота;
  - приём сигнала перевода от бота (SIP REFER или AMI Redirect);
  - конфиг бота (`config.py`), модуль `asterisk_transfer.py`, интеграция в `demo_main.py`.
- **`TELEGRAM_BOT_SPEC.md`** — спецификация Telegram-бота.
- **`CALL_ANALYTICS_SPEC.md`** — аналитика звонков: смешанная схема (автозабор SpRecord3 + ручная загрузка), админка (результаты, прослушивание), дашборд (графики), PostgreSQL, интеграция с Asterisk/1С.
- **`docs/CALL_TYPES_CLASSIFICATION.md`** — **виды звонков** (ОП вх./исх., СТО вх./исх., Прочие): принцип отбора и маркеры для чтения без кода.

---

## Интеграция с внешними системами

- **`Infolada_answers.txt`** — ответы Инфолады по SpRecord, SIP к боту, DID.
- **`Infolada_questions.txt`** — вопросы для Инфолады (запись, бот, номера).

---

## Запуск

- **`telegram_bot/README.md`** — запуск Telegram-бота.
- **`admin_panel/README.md`** — запуск веб-админки аналитики звонков (FastAPI, список звонков, загрузка, прослушивание).
- Голосовой бот: `python demo_main.py` (см. `config.py`, ярлык Vikingi Demo Bot).
