# Исправление ярлыка на рабочем столе

## Проблема
Ярлык не запускается при двойном клике.

## Решение

### Вариант 1: Использовать существующий ярлык
Ярлык `Vikingi_demo.desktop` на рабочем столе обновлен и должен работать.

**Если не работает:**
1. Правой кнопкой мыши на ярлык → "Свойства" → вкладка "Права"
2. Убедитесь, что стоит галочка "Разрешить выполнение файла как программы"
3. Или в терминале:
   ```bash
   chmod +x ~/Рабочий\ стол/Vikingi_demo.desktop
   ```

### Вариант 2: Запуск через терминал
Откройте терминал и выполните:
```bash
cd ~/Vikingi
./Vikingi_demo.sh
```

### Вариант 3: Создать новый ярлык вручную
1. Правой кнопкой на рабочем столе → "Создать новый файл" → "Ярлык к программе"
2. В поле "Команда" введите:
   ```bash
   gnome-terminal --title="Vikingi Demo Bot" -- bash -c "cd /home/romandemo/Vikingi && ./Vikingi_demo.sh; echo ''; echo 'Нажмите Enter для закрытия...'; read"
   ```
3. Название: "Vikingi Demo Bot"
4. Сохраните

### Вариант 4: Использовать альтернативный терминал
Если `gnome-terminal` не работает, используйте `Vikingi_demo_alt.desktop` (использует `xterm`)

## Проверка
1. Двойной клик по ярлыку должен открыть терминал с запущенным ботом
2. Если открывается пустой терминал - проверьте путь к скрипту
3. Если появляется ошибка - проверьте логи в `~/Vikingi/vikingi_demo.log`

## Отладка
Если ярлык не работает, проверьте в терминале:
```bash
# Проверить права
ls -la ~/Рабочий\ стол/Vikingi_demo.desktop

# Попробовать запустить вручную
gnome-terminal --title="Vikingi Demo Bot" -- bash -c "cd /home/romandemo/Vikingi && ./Vikingi_demo.sh; read"
```
