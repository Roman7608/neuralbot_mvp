Переводы бота SpRecord по дате Звонки Загрузка Лиды Аналитика СТО

Список файлов с шары sprecord_arch (корень /mnt/sprecord), имя вида ГГГГ_ММ_ДД_ЧЧ_ММ_СС_… — дата в календаре должна соответствовать дате в имени файла. Сверяйте дату и время с сессией на странице «Переводы бота». Прослушивание — кнопка «Слушать» (файл подгружается через запрос с сессией; встроенный src у плеера без cookie часто не воспроизводится). Лимит строк на запрос ограничен; при большом дне сузьте диапазон дат.
