# Решение проблем с Dual Boot (Ubuntu + Windows)

## 🔍 Текущая ситуация

**Проблема:** Ubuntu загружается только с загрузочной флешки, хотя должна загружаться с жесткого диска.

---

## ✅ Как должна работать нормальная Dual Boot система

### После правильной установки:

1. **При включении компьютера:**
   - Появляется меню GRUB (загрузчик Linux)
   - Можно выбрать: Ubuntu или Windows
   - **Флешка НЕ нужна**

2. **Загрузка происходит с жесткого диска:**
   - Ubuntu установлена на раздел жесткого диска
   - GRUB установлен в MBR или EFI раздел
   - Windows загрузчик доступен через GRUB

---

## ⚠️ Почему может требоваться флешка

### Возможные причины:

1. **Ubuntu не установлена на жесткий диск**
   - Запускается только в режиме "Try Ubuntu" (Live USB)
   - Не установлена на диск

2. **GRUB не установлен или поврежден**
   - Загрузчик не видит Ubuntu
   - Windows загружается напрямую, минуя GRUB

3. **Проблема с EFI/UEFI**
   - Неправильная настройка загрузки UEFI
   - Ubuntu установлена в Legacy режиме, а Windows в UEFI (или наоборот)

4. **Раздел с Ubuntu не помечен как загрузочный**
   - Раздел существует, но не активен

---

## 🔧 Диагностика

### Шаг 1: Проверить, установлена ли Ubuntu на диск

**В Ubuntu (загруженной с флешки):**

```bash
# Проверить разделы диска
sudo fdisk -l

# Или
sudo lsblk -f
```

**Что искать:**
- Раздел с файловой системой `ext4` (обычно `/dev/sdaX` или `/dev/nvme0n1pX`)
- Раздел с размером, соответствующим установленной Ubuntu (например, 50-100 ГБ)

**Если раздела нет:**
- Ubuntu не установлена, только запускается с флешки
- Нужно установить Ubuntu на диск

### Шаг 2: Проверить наличие GRUB

```bash
# Проверить, установлен ли GRUB
sudo grub-install --version

# Проверить конфигурацию GRUB
sudo cat /boot/grub/grub.cfg | head -20
```

### Шаг 3: Проверить режим загрузки

```bash
# Проверить, в каком режиме загружена система
ls /sys/firmware/efi

# Если папка существует - UEFI режим
# Если не существует - Legacy режим
```

## 🛠️ Решения

### Решение 1: Установить Ubuntu на жесткий диск

**Если Ubuntu не установлена:**

1. Загрузиться с флешки
2. Запустить установщик Ubuntu
3. Выбрать "Установить рядом с Windows" (Install alongside Windows)
4. Выделить место для Ubuntu (например, 50-100 ГБ)
5. Завершить установку
6. После установки GRUB будет установлен автоматически

**Важно:**
- Сделать резервную копию важных данных перед установкой
- Убедиться, что есть свободное место на диске

### Решение 2: Восстановить GRUB

**Если Ubuntu установлена, но GRUB не работает:**

#### Вариант A: Восстановление из Ubuntu (загруженной с флешки)

```bash
# 1. Найти раздел с Ubuntu
sudo fdisk -l
# Запомнить номер раздела (например, /dev/sda5)

# 2. Смонтировать раздел
sudo mkdir /mnt/ubuntu
sudo mount /dev/sda5 /mnt/ubuntu

# 3. Если есть отдельный раздел /boot/efi
sudo mount /dev/sda1 /mnt/ubuntu/boot/efi  # если есть

# 4. Примонтировать системные разделы
sudo mount --bind /dev /mnt/ubuntu/dev
sudo mount --bind /proc /mnt/ubuntu/proc
sudo mount --bind /sys /mnt/ubuntu/sys
sudo mount --bind /run /mnt/ubuntu/run

# 5. Войти в chroot
sudo chroot /mnt/ubuntu

# 6. Установить/восстановить GRUB
grub-install /dev/sda  # для Legacy
# или
grub-install /dev/sda --efi-directory=/boot/efi  # для UEFI

# 7. Обновить конфигурацию GRUB
update-grub

# 8. Выйти из chroot
exit

# 9. Перезагрузиться (без флешки)
```

#### Вариант B: Использовать Boot Repair (проще)

```bash
# 1. Установить Boot Repair
sudo add-apt-repository ppa:yannubuntu/boot-repair
sudo apt update
sudo apt install boot-repair

# 2. Запустить Boot Repair
sudo boot-repair

# 3. Следовать инструкциям (обычно "Recommended repair")
```

### Решение 3: Настроить UEFI/BIOS

**Проблема:** Windows и Ubuntu в разных режимах загрузки

**Решение:**
1. Войти в BIOS/UEFI (обычно F2, F12, Del при загрузке)
2. Проверить режим загрузки:
   - **UEFI** (рекомендуется для современных систем)
   - **Legacy/CSM** (старые системы)
3. Убедиться, что Ubuntu и Windows установлены в одном режиме
4. Установить приоритет загрузки:
   - Ubuntu/GRUB должен быть первым
   - Или использовать меню выбора загрузки (F12 при старте)

## ❓ Можно ли вынимать флешку после загрузки?

### Ответ: **ДА, можно, НО...**

**Если Ubuntu загружена с флешки (Live USB):**
- ✅ Можно вынуть флешку после полной загрузки
- ⚠️ Но это означает, что Ubuntu работает в режиме Live (временная система)
- ⚠️ Все изменения будут потеряны после перезагрузки
- ⚠️ Это не постоянная установка

**Если Ubuntu установлена на диск:**
- ✅ После установки флешка не нужна
- ✅ Можно вынуть сразу после начала загрузки
- ✅ Система загрузится с жесткого диска

## 🎯 Рекомендации

### Для постоянной работы:

1. **Установить Ubuntu на жесткий диск** (если еще не установлена)
   - Выделить отдельный раздел (50-100 ГБ)
   - Использовать режим "Установить рядом с Windows"

2. **После установки:**
   - Флешка больше не нужна
   - При загрузке появится меню GRUB
   - Можно выбрать Ubuntu или Windows

3. **Если GRUB не появляется:**
   - Использовать Boot Repair для восстановления
   - Или восстановить GRUB вручную (см. выше)

## ✅ Решение для вашей ситуации

**Диагностика показала:**
- ✅ Ubuntu установлена на диск (`nvme0n1p5`)
- ✅ GRUB установлен (`/boot/grub/grub.cfg` существует)
- ✅ Режим загрузки: UEFI
- ⚠️ Проблема: GRUB не появляется при загрузке без флешки

**Решение:**

### Шаг 1: Восстановить GRUB в EFI раздел

```bash
# Восстановить GRUB
sudo grub-install --target=x86_64-efi --efi-directory=/boot/efi --bootloader-id=Ubuntu

# Обновить конфигурацию
sudo update-grub
```

### Шаг 2: Проверить записи загрузки UEFI

```bash
sudo efibootmgr -v
```

**Должна быть запись с "Ubuntu" в списке.**

### Шаг 3: Настроить приоритет загрузки в UEFI

1. Перезагрузите компьютер
2. При загрузке нажмите **F12** (или другую клавишу для меню загрузки - обычно указано на экране)
3. Выберите **"Ubuntu"** из списка
4. Если Ubuntu не появляется:
   - Войдите в **BIOS/UEFI** (обычно **F2** или **Del**)
   - Найдите раздел **"Boot"** или **"Загрузка"**
   - Найдите **"Boot Priority"** или **"Приоритет загрузки"**
   - Установите **"Ubuntu"** первым в списке
   - Сохраните изменения (**F10**) и перезагрузитесь

### Шаг 4: Проверить работу

После настройки:
1. Выньте флешку
2. Перезагрузите компьютер
3. Должно появиться меню GRUB с выбором Ubuntu или Windows
4. Выберите нужную систему

**Если проблема сохраняется:**
- Используйте скрипт `fix_grub_boot.sh` для автоматического восстановления
