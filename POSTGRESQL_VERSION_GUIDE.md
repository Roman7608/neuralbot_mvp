# Руководство по выбору версии PostgreSQL

## 📅 Жизненный цикл поддержки PostgreSQL

### Текущие версии и сроки поддержки (на январь 2026):

- **PostgreSQL 14**: Поддержка до **ноября 2026** (осталось ~10 месяцев)
- **PostgreSQL 15**: Поддержка до **ноября 2027** (еще ~1 год 10 месяцев)
- **PostgreSQL 16**: Поддержка до **ноября 2028** (еще ~2 года 10 месяцев)

---

## ❓ Что означает "прекращение поддержки"?

**Важно понимать:**
- ❌ **НЕ означает**, что база данных перестанет работать
- ❌ **НЕ означает**, что нужно срочно обновляться
- ✅ **Означает**, что не будет:
  - Обновлений безопасности (критические исправления)
  - Исправлений ошибок
  - Новых патчей

**База данных продолжит работать нормально**, но:
- Не будет получать обновления безопасности
- Риск уязвимостей со временем увеличивается
- Рекомендуется обновление до поддерживаемой версии

---

## 🔄 Что делать, когда поддержка прекратится?

### Вариант 1: Обновление PostgreSQL (рекомендуется)

**PostgreSQL поддерживает обновление между версиями:**

1. **Минорные обновления** (14.1 → 14.9):
   - Простое обновление пакетов
   - Без изменений в данных
   - Без простоя

2. **Мажорные обновления** (14 → 15, 15 → 16):
   - Требуется миграция данных
   - Используется утилита `pg_upgrade`
   - Обычно занимает несколько часов
   - Требуется резервное копирование

**Процесс обновления:**
```bash
# 1. Резервное копирование
pg_dumpall > backup.sql

# 2. Установка новой версии
sudo apt install postgresql-15

# 3. Обновление данных
sudo pg_upgrade -d /var/lib/postgresql/14/main -D /var/lib/postgresql/15/main

# 4. Проверка и запуск новой версии
```

**Преимущества:**
- Сохраняются все данные
- Минимальный простой
- Автоматизированный процесс

### Вариант 2: Остаться на версии 14 (не рекомендуется для продакшена)

**Можно использовать, но:**
- ⚠️ Нет обновлений безопасности
- ⚠️ Риск уязвимостей
- ⚠️ Не рекомендуется для систем с важными данными

**Подходит для:**
- Тестовых окружений
- Внутренних систем без внешнего доступа
- Временных решений

### Вариант 3: Использовать коммерческую поддержку

**PostgreSQL Pro, EnterpriseDB и др. предлагают:**
- Расширенную поддержку старых версий
- Консультации по обновлению
- Гарантированную поддержку

**Стоимость:** От $5000/год (обычно не требуется для небольших проектов)

## 📋 План обновления (когда придет время)

### За 3 месяца до прекращения поддержки:

1. **Оценка текущей системы:**
   - Размер базы данных
   - Количество подключений
   - Используемые функции PostgreSQL

2. **Подготовка тестовой среды:**
   - Установка новой версии PostgreSQL
   - Копирование данных
   - Тестирование приложений

3. **Планирование миграции:**
   - Выбор окна для обновления (обычно выходные)
   - Подготовка резервных копий
   - Информирование пользователей

### За 1 месяц до прекращения поддержки:

1. **Финальное тестирование**
2. **Подготовка скриптов миграции**
3. **Назначение ответственных**

### В день обновления:

1. Резервное копирование
2. Остановка сервисов
3. Обновление PostgreSQL
4. Миграция данных
5. Проверка работы
6. Запуск сервисов

---

## 🔒 Безопасность после прекращения поддержки

**Если не обновились вовремя:**

1. **Изоляция базы данных:**
   - Ограничить доступ извне
   - Использовать файрвол
   - Только внутренний доступ

2. **Мониторинг:**
   - Отслеживать попытки несанкционированного доступа
   - Логировать все подключения
   - Регулярно проверять логи

3. **Планирование обновления:**
   - Обновление остается приоритетом
   - Планировать в ближайшее время
