# Установка PostgreSQL 16

## Расположение скрипта

Скрипт установки находится в директории проекта:
```
/home/romandemo/Vikingi/install_postgresql_16.sh
```

## Запуск установки

### Вариант 1: Перейти в директорию проекта
```bash
cd ~/Vikingi
./install_postgresql_16.sh
```

### Вариант 2: Запустить с полным путем
```bash
~/Vikingi/install_postgresql_16.sh
```

## Что делает скрипт

1. Устанавливает необходимые пакеты (wget, ca-certificates)
2. Добавляет официальный репозиторий PostgreSQL
3. Устанавливает PostgreSQL 16 и contrib
4. Включает автозапуск службы
5. Проверяет установку

## После установки

Скрипт покажет инструкции по созданию базы данных и пользователей.
