# Telegram-бот для проекта Vikingi

## Установка

1. Установите зависимости:
```bash
pip install -r requirements_telegram.txt
```

2. Убедитесь, что файл `telegram_bot_config.py` содержит правильные настройки (токен бота, ID групп).

## Запуск

```bash
python -m telegram_bot.bot
```

Или:

```bash
python telegram_bot/bot.py
```

## Структура проекта

```
telegram_bot/
├── __init__.py
├── bot.py                 # Основной файл бота
├── states.py              # Состояния FSM
├── handlers/              # Обработчики сообщений
│   ├── __init__.py
│   ├── start.py          # Команда /start
│   └── lead_handler.py   # Обработка заявок
├── services/              # Сервисы
│   ├── __init__.py
│   ├── need_detector.py  # Определение потребности
│   ├── group_router.py   # Маршрутизация в группы
│   └── ics_alfa_service.py # Интеграция с 1С
└── utils/                 # Утилиты
    ├── __init__.py
    ├── phone_normalizer.py # Нормализация телефонов
    └── time_utils.py      # Работа со временем
```

## Функциональность

- ✅ Прием заявок от клиентов
- ✅ Определение потребности по ключевым словам
- ✅ Маршрутизация в группы отделов
- ✅ Нормализация телефонных номеров
- ✅ Определение рабочего/нерабочего времени
- ⏳ Интеграция с 1С Альфа 6.0 (заглушка)
- ⏳ Напоминания о записи (в разработке)
- ⏳ Обработка фото (в разработке)
- ⏳ Оценка после визита (в разработке)

## Логи

Логи сохраняются в файл `telegram_bot.log`.
