# Решение проблем с USB-микрофоном

## На основе инструкции к микрофону

### Важные настройки:

1. **Частота дискретизации:**
   - Микрофон поддерживает: 48 kHz
   - Система автоматически ресемплирует при необходимости

2. **Подключение:**
   - ✅ Подключайте микрофон **напрямую** к USB-порту компьютера
   - ❌ Избегайте USB-хабов для лучшей производительности

3. **Разрешения:**
   - Убедитесь, что приложения имеют разрешение на использование микрофона
   - В Ubuntu: Настройки → Конфиденциальность → Микрофон

### Решение проблем:

#### Микрофон слишком тихий:
```bash
# Увеличить уровень громкости до 80%
pactl set-source-volume $(pactl list sources short | grep -i "usb.*microphone" | head -1 | awk '{print $1}') 80%
```

#### Микрофон беззвучен:
```bash
# Установить как устройство по умолчанию
pactl set-default-source $(pactl list sources short | grep -i "usb.*microphone" | head -1 | awk '{print $1}')

# Проверить, что не заглушен
pactl set-source-mute $(pactl list sources short | grep -i "usb.*microphone" | head -1 | awk '{print $1}') 0
```

#### Микрофон слишком громкий (искажения, шум):
```bash
# Уменьшить уровень громкости
pactl set-source-volume $(pactl list sources short | grep -i "usb.*microphone" | head -1 | awk '{print $1}') 50%
```

### Проверка текущих настроек:
```bash
# Показать информацию о микрофоне
pactl list sources | grep -A 15 "USB microphone"
```

### Технические характеристики (из инструкции):
- **Частота дискретизации:** 48 kHz
- **Чувствительность:** -38±3dB
- **Частотная характеристика:** 20Hz-20KHz
- **Диаграмма направленности:** Кардиоидная (фокусируется на звуке спереди)
- **Соотношение сигнал/шум:** 95dB

### Рекомендации:
1. Говорите **на переднюю часть микрофона** (кардиоидная диаграмма)
2. Держите микрофон на расстоянии 15-30 см от рта
3. Избегайте фонового шума (микрофон хорошо его подавляет спереди)
