# Админка с ноутбука (server7)

Рабочая среда: ноутбук в Cursor по SSH на server7 (192.168.0.7), порт 8000 открыт.

## Как открыть админку

### Вариант 1: SSH port forwarding (рекомендуется)

На **ноутбуке** (в локальном терминале):

```bash
ssh -L 8000:localhost:8000 vikingi@192.168.0.7
```

После подключения откройте в браузере: **http://localhost:8000**

Туннель активен, пока держится SSH-сессия.

### Вариант 2: Прямой доступ по IP

В браузере: **http://192.168.0.7:8000**

(Если порт 8000 доступен из вашей сети.)

---

## Админка не открывается — что проверить

1. **Контейнер работает?** (выполнить на server7)
   ```bash
   docker ps -a --filter "name=admin-panel"
   ```

2. **Логи контейнера** (ошибки при старте)
   ```bash
   cd ~/VikingiAll
   docker compose logs admin-panel --tail 50
   ```

3. **Пересборка после изменений в коде**
   ```bash
   cd ~/VikingiAll
   docker compose build admin-panel --no-cache
   docker compose up -d admin-panel
   ```

4. **SSH port forwarding не срабатывает?**
   - Проверьте, что SSH-сессия с `-L 8000:localhost:8000` активна
   - Не открывайте localhost:8000 в браузере на server7 — только на ноутбуке

5. **Порт занят на ноутбуке?**  
   Если 8000 занят, используйте другой локальный порт:
   ```bash
   ssh -L 8080:localhost:8000 vikingi@192.168.0.7
   ```
   Затем в браузере: http://localhost:8080
