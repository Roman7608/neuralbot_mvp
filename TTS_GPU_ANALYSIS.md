# Анализ использования TTS и предзаписанных WAV-файлов

## ✅ TTS теперь работает на GPU

Модель Silero TTS автоматически переносится на GPU после загрузки, если GPU доступен. Это должно значительно ускорить синтез речи.

**Изменения:**
- Модель TTS загружается и переносится на GPU в методе `SileroTTS.init()`
- При синтезе аудио автоматически переносится с GPU на CPU для воспроизведения
- Если GPU недоступен, модель работает на CPU (fallback)

## 🎤 Фразы, синтезируемые через TTS (динамические)

Следующие фразы **синтезируются** через TTS, так как содержат динамические данные:

### 1. Динамические фразы (TTS)
- `"Я правильно поняла, Вас интересует …?"` - Подтверждение потребности (без имени)
- Фразы с датами и временем для записи на сервис

### 2. Фразы с датами и временем (нельзя предзаписать)
- `_format_offer(slot_date, slot_time)` - Предложение времени записи
  - Пример: "Предлагаю записаться на {дата} в {время}"
  - Используется в 4 местах кода

### 3. Статичные фразы, которые МОЖНО предзаписать (но пока синтезируются)
- `"Повторите, пожалуйста."` - Повтор запроса
- `"Прошу прощения, я Вас не слышу. До свидания!"` - Ошибка слышимости
- `"Назовите, пожалуйста, пробег."` - Запрос пробега
- `"Назовите, пожалуйста, список работ."` - Запрос списка работ
- `"Назовите, пожалуйста, пробег и желаемый список работ."` - Запрос пробега и работ
- `"Повторите, пожалуйста, удобное время."` - Повтор времени
- `"Я Вас не совсем поняла. Скажите, пожалуйста, «да» или «нет»."` - Непонимание
- Выбор отдела (12_ask_department.wav, TTS по greeting_type):
  - DID на бота (697777, 697070, 695875, 695870, 707755 и др. по маршрутизации): единый текст Чери/Тэнет — «Я могу соединить Вас с Отделом продаж автомобилей Ч+ери и Тен+эт, …». **773399** на бота не ведёт (отдельный маршрут в УАТС).

### 4. Служебные фразы
- `"Пока что я не подключена к LLM, но это место для её ответа."` - Заглушка для LLM

## 💡 Рекомендации по оптимизации

### Можно предзаписать (ускорит работу):
1. `"Повторите, пожалуйста."` → `17_repeat.wav`
2. `"Назовите, пожалуйста, пробег."` → `18_ask_mileage.wav`
3. `"Назовите, пожалуйста, список работ."` → `19_ask_works.wav`
4. `"Назовите, пожалуйста, пробег и желаемый список работ."` → `20_ask_mileage_works.wav`
5. `"Повторите, пожалуйста, удобное время."` → `21_repeat_time.wav`
6. `"Я Вас не совсем поняла. Скажите, пожалуйста, «да» или «нет»."` → `22_ask_yes_no.wav`
7. `"Прошу прощения, я Вас не слышу. До свидания!"` → `23_cannot_hear.wav`

### Нельзя предзаписать (требуют TTS):
- Все фразы с именами клиентов
- Все фразы с датами и временем
- Фразы с выбором отделов (содержат имя)

## 🚀 Ожидаемый эффект от переноса TTS на GPU

1. **Ускорение синтеза:** Синтез речи на GPU должен быть в 2-5 раз быстрее, чем на CPU
2. **Снижение пауз:** Время от распознавания до ответа должно сократиться
3. **Параллельная работа:** GPU может обрабатывать TTS параллельно с другими задачами
