# 🚀 Краткая инструкция - Голосовой бот готов!

## ✅ Что работает прямо сейчас

1. ✅ **MicroSIP → Asterisk** - звонки с голосом работают
2. ✅ **Asterisk → API** - события приходят автоматически  
3. ✅ **API → PostgreSQL** - все звонки записываются
4. ✅ **Код голосового бота** - готов, ждет API ключи

---

## ⚡ Запуск системы (3 команды)

```powershell
# 1. Запуск Docker
docker compose -f docker-compose.test.yml up -d

# 2. Запуск мониторинга Asterisk
powershell -ExecutionPolicy Bypass -File .\start_monitoring.ps1

# 3. Проверка статуса
curl http://localhost:8000/internal/bot/status
```

---

## 🔑 Что нужно для голосового бота

### Получите на https://developers.sber.ru/

1. **GigaChat Client ID**
2. **GigaChat Auth Key**
3. **Salute Speech Client ID**
4. **Salute Speech Auth Key**

### Создайте файл `.env`:

```bash
LLM_PROVIDER=gigachat
GIGACHAT_CLIENT_ID=your_client_id
GIGACHAT_AUTH_KEY=your_auth_key
GIGACHAT_SCOPE=GIGACHAT_API_PERS

SALUTE_CLIENT_ID=your_client_id
SALUTE_AUTH_KEY=your_auth_key
SALUTE_SCOPE=SALUTE_SPEECH_PERS
```

### Перезапустите API:

```powershell
docker compose -f docker-compose.test.yml restart api
powershell -ExecutionPolicy Bypass -File .\start_monitoring.ps1
```

## 🧪 Тестирование

### Простой тест (без API ключей - покажет ошибку):
```powershell
curl.exe --% -X POST "http://localhost:8000/internal/bot/chat" -H "Content-Type: application/json" -d "{\"message\":\"Привет\"}"
```

### С API ключами:
```powershell
curl.exe --% -X POST "http://localhost:8000/internal/bot/chat" -H "Content-Type: application/json" -d "{\"message\":\"Хочу купить Chery\"}"
```

**Ответ:**
```json
{
  "ok": true,
  "bot_response": "Отлично! Какую модель Chery вас интересует?...",
  "provider": "GigaChat"
}
```
