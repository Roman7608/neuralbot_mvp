# Статус проекта: Голосовой ассистент на Asterisk + Локальные LLM/STT/TTS

## 📋 ТРЕБОВАНИЯ К ПРОЕКТАМ

### ПРОЕКТ 1: Основной (Продакшн)

**Архитектура:**
- **Облачный сервер Asterisk** (на стороне заказчика)
  - SIP через Инфолад
  - Принимает входящие звонки
  - RTP проксирование в локальный компьютер
  - Маршрутизация на внутренние номера (1-12)
  - Запись звонков (выборочная, по определённым номерам)

- **Локальный компьютер в офисе** (24/7 работа)
  - Связь с Asterisk по публичному IP
  - Обработка до 5 одновременных звонков
  - Полный пайплайн: STT → LLM → TTS (все локально, offline)
  - Интеграция с 1С Альфа (поиск клиентов, слотов, создание записей)
  - Работа с Excel файлами (трудоёмкости операций, журнал записи)
  - RAG система с 20 предзаписанными аудиоответами (TTS синтез)
  - Перевод звонков на внутренние номера (12 номеров)
  - Telegram уведомления при занятости номеров
  - Запись звонков (7 дней хранения, локально)
  - Админ-панель для прослушивания и оценки звонков

- **Хранилище аудио server7 (важно)**
  - На server7 два носителя: SSD (проект) и HDD (аудио)
  - Все аудиозаписи звонков сохраняются **только на HDD** (`/mnt/audio_calls/calls/`)
  - Автозабор из SpRecord → `/mnt/audio_calls/calls/auto/YYYY-MM-DD/`
  - Ручная загрузка через админку → `/mnt/audio_calls/calls/manual/OP/` и `/STO/`
  - Админка и блок аналитики имеют доступ к HDD через монтирование в Docker

**Функциональность:**
- Поиск клиента по ФИО или телефону в базе 1С
- Определение времени на ремонт (марка/модель/двигатель + операции из Excel)
- Поиск свободных слотов в карточке записи 1С
- Предложение слотов клиенту и создание записи в 1С
- Оценка звонков по стандартам продаж (LLM анализ транскриптов)
- Перевод звонков по ключевым словам или прямому указанию клиента

**Ограничения:**
- Задержка ответа: **до 2 секунд** (критично)
- Все модели локально (STT, TTS, LLM) - offline работа
- Русский язык
- **GPU:** STT голосового бота занимает GPU круглосуточно. LLM аналитики (нормализация, оценка, классификация) — запускать **только после 23:50** (см. DEPLOYMENT_GUIDE.md)

## 🧪 ПОСЛЕДНИЙ ЭТАП: ТЕСТ УСТАНОВЛЕННОЙ LLM

### Цель теста
Проверить, что модель Saiga Llama3 8B Q4_K_M:
- Загружается в память (VRAM/RAM)
- Генерирует ответы на русском языке
- Работает с llama-cpp-python
- Имеет приемлемую скорость генерации

### Тестовый скрипт

**Файл:** `test_llm.py`

```python
from llama_cpp import Llama
import time
import sys

def test_llm():
    model_path = "/home/romandemo/models/qwen/model-q4_K.gguf"
    
    print("=" * 60)
    print("ТЕСТ LLM: Saiga Llama3 8B Q4_K_M")
    print("=" * 60)
    
    # Загрузка модели
    print("\n[1/4] Загрузка модели...")
    try:
        llm = Llama(
            model_path=model_path,
            n_ctx=2048,  # Размер контекста
            n_gpu_layers=-1,  # Максимально на GPU
            verbose=False,
        )
        print("✅ Модель загружена успешно")
    except Exception as e:
        print(f"❌ Ошибка загрузки модели: {e}")
        return False
    
    # Тест 1: Простое приветствие
    print("\n[2/4] Тест 1: Приветствие и представление")
    prompt1 = "Ты вежливый русскоязычный голосовой ассистент автосервиса. Ответь коротко: привет, представься и спроси, чем помочь."
    print(f"Промпт: {prompt1}")
    
    start = time.time()
    try:
        out1 = llm(prompt1, max_tokens=128, stop=["</s>", "###"], stream=False)
        time1 = time.time() - start
        response1 = out1['choices'][0]['text'].strip()
        tokens1 = len(response1.split())
        
        print(f"Ответ: {response1}")
        print(f"Время генерации: {time1:.2f} сек")
        print(f"Токенов сгенерировано: ~{tokens1}")
        print(f"Скорость: ~{tokens1/time1:.1f} токенов/сек")
    except Exception as e:
        print(f"❌ Ошибка генерации: {e}")
        return False
    
    # Тест 2: Вопрос о записи
    print("\n[3/4] Тест 2: Вопрос о записи на сервис")
    prompt2 = "Клиент спрашивает: 'Можно записаться на завтра?' Ответь коротко и вежливо."
    print(f"Промпт: {prompt2}")
    
    start = time.time()
    try:
        out2 = llm(prompt2, max_tokens=64, stop=["</s>", "###"], stream=False)
        time2 = time.time() - start
        response2 = out2['choices'][0]['text'].strip()
        tokens2 = len(response2.split())
        
        print(f"Ответ: {response2}")
        print(f"Время генерации: {time2:.2f} сек")
        print(f"Токенов сгенерировано: ~{tokens2}")
        print(f"Скорость: ~{tokens2/time2:.1f} токенов/сек")
    except Exception as e:
        print(f"❌ Ошибка генерации: {e}")
        return False
    
    # Тест 3: Информация о модели
    print("\n[4/4] Информация о модели")
    print(f"Контекст: {llm.n_ctx} токенов")
    print(f"GPU слои: {llm.n_gpu_layers} (все на GPU)")
    print(f"Путь к модели: {model_path}")
    
    # Проверка времени ответа
    avg_time = (time1 + time2) / 2
    print(f"\n📊 Среднее время генерации: {avg_time:.2f} сек")
    
    if avg_time < 2.0:
        print("✅ Время ответа < 2 сек - соответствует требованиям!")
    else:
        print("⚠️  Время ответа > 2 сек - требуется оптимизация")
    
    print("\n" + "=" * 60)
    print("✅ ТЕСТ LLM ЗАВЕРШЁН УСПЕШНО")
    print("=" * 60)
    
    return True

if __name__ == "__main__":
    success = test_llm()
    sys.exit(0 if success else 1)
```


### Ожидаемые результаты
- Модель загружается без ошибок
- Генерирует осмысленные ответы на русском
- Время генерации 64-128 токенов: **0.8-1.5 секунд**
- Модель использует GPU (проверка через `nvidia-smi` во время генерации)

### Возможные проблемы
- **Out of memory:** Уменьшить `n_gpu_layers` или использовать CPU offloading
- **Медленная генерация:** Проверить, что модель на GPU (`n_gpu_layers=-1`)
- **Некорректные ответы:** Проверить формат промпта (Saiga использует формат Llama3)
