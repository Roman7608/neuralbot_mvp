## Повторная настройка паролей

```bash
# Из корня проекта (Postgres должен быть доступен)
POSTGRESQL_HOST=localhost POSTGRESQL_PORT=5433 POSTGRESQL_ANALYTICS_PASSWORD=TOP python scripts/setup_admin_users.py
```

Или смена пароля одного пользователя:
```bash
python -m admin_panel.set_admin_password LOGIN NEW_PASSWORD
```
