## Пароли

Пароли **не хранятся в коде** — только в базе данных в виде хешей. Их нельзя извлечь. Нужно:
1. Создать пользователей: `python -m admin_panel.create_admin_user LOGIN PASSWORD ROLE_ID`
2. Записать пароли и вписать их в инструкции вручную.
