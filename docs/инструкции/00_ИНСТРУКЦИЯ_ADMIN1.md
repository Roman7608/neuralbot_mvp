# Учётная запись admin1 (суперадмин платформы)

## Назначение

**admin1** — не «ещё один директор для повседневной работы», а учётка **владельца проекта / разработчика / администратора server7**: полный доступ к веб-админке **и** ответственность за инфраструктуру вне браузера (SSH, Docker, PostgreSQL, бэкапы, секреты).

**Иерархия:** в системе ролей номер **8** выше, чем у директора (**6**). В интерфейсе админки на текущий момент доступны **те же разделы и действия**, что у роли 6, плюс журнал **«Переводы бота»** (как у директора). Разделение 6 и 8 заложено для учёта и для возможных будущих отличий (например, ограничить что-то только для бизнес-ролей).

| | Директор (`admin`, роль 6) | Суперадмин (`admin1`, роль 8) |
|---|---------------------------|------------------------------|
| Все разделы админки | да | да |
| Смысл использования | работа руководства | платформа, техподдержка, аудит |
| Доступ к серверу по SSH | по политике компании | предполагается |

Пароль **не хранится в репозитории**. Записывается в закрытый конспект / менеджер паролей.

---

## Вход

- **Адрес:** `http://[адрес_сервера]:8000/login`
- **Логин:** `admin1`
- **Пароль:** (задаётся при создании учётной записи, см. ниже)

После входа доступны те же пункты меню, что у директора: **Звонки**, **Загрузка**, **Лиды**, **Аналитика**, **Переводы бота**, **СТО** (в пределах прав, см. `admin_panel/auth.py`, роль **8**).

---

## Создание и смена пароля

1. На сервере должна быть применена миграция БД `database/migrations/012_admin_role8_superadmin.sql` (допускает `role_id` до **8**).

2. Создать пользователя (из корня проекта, с доступом к PostgreSQL):

   ```bash
   python -m admin_panel.create_admin_user admin1 'Надёжный_пароль' 8
   ```

   В Docker:

   ```bash
   docker compose exec admin-panel python -m admin_panel.create_admin_user admin1 'Надёжный_пароль' 8
   ```

3. Смена пароля существующего логина:

   ```bash
   python -m admin_panel.set_admin_password admin1 'Новый_пароль'
   ```

---

## Смена пользователя в браузере

Отдельной кнопки «Выход» может не быть: чтобы войти под другим логином, удалите cookie **`admin_session`** для сайта админки или откройте **приватное окно**.
