## Кузовной цех (отдельный справочник)

Используется **только вместе** с признаком «кузовн…» в тексте (классификация и др.). Имена и фамилии из списка; в логике активны **отдельные слова** (например «Павел», «Горбушин», «Олег»).

| Фамилия   | Имя     | Отображаемое (ключ в коде — manager_name) |
|-----------|---------|-------------------------------------------|
| Горбушин  | Дмитрий | Горбушин Дмитрий |
| Алексеев  | Павел   | Алексеев Павел |
| Захаров   | Олег    | Захаров Олег |
| Белоногов | Олег    | Белоногов Олег |

*Захаров Олег (кузовной) не смешивать с Захаров Илья (ОП) — различие по контексту кузовного.*

## Где используется

- **admin_panel/managers_config.py** — `OP_MANAGERS`, `STO_MANAGERS` для фильтра Аналитики; `KUZOV_BODY_MANAGERS`, `get_kuzov_body_word_tokens()` для кузовного цеха
- **call_analytics/classify_by_transcript.py** — `_OP_MANAGER_NAMES`, `_STO_MANAGER_NAMES` для правила «говорящий не в списке → OTHER»; кузовной — `_is_body_shop_master_opening` + токены из `get_kuzov_body_word_tokens`
