0) Согласовать с Инфоладой: «переключаем сейчас» (мы и они — одновременно).

1) Сменить SIP-хост в .env:

  sed -i 's/^INFOLADA_SIP_HOST=.*/INFOLADA_SIP_HOST=81.23.191.220/' .env
  grep INFOLADA_SIP_HOST .env

2) UFW — разрешить новый IP (старый можно оставить на переходный период):

  sudo ufw allow from 81.23.191.220 to any port 5060 proto udp
  sudo ufw allow from 81.23.191.220 to any port 5060 proto tcp
  sudo ufw allow from 81.23.191.220 to any port 10000:10100 proto udp

3) Пересоздать конфиг Asterisk и поднять контейнер:

  docker exec vikingiall-asterisk-1 asterisk -rx "pjsip show registrations"
  docker compose ps asterisk
