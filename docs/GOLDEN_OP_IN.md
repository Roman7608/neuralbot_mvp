# Золотой стандарт: ОП вход (`OP_IN`)

Эталонные транскрипты для регрессии **широкого слоя** классификации: отдел `OP`, тип `OP_IN`.

**Код классификатора:** `call_analytics/classify_by_transcript.py` → `classify_auto`.

**Фикстуры:** `call_analytics/fixtures/classify_golden_op_in.json`

**Тест:**

```bash
python -m unittest call_analytics.test_classify_golden_op_in -v
```

Общий golden (все типы): `classify_golden_cases.json` + `test_classify_golden.py`.

Оценка качества разговора **после** классификации (14 критериев): `docs/OP_CALL_EVALUATION_CRITERIA_RUBRIC.md`, `call_analytics/op_in_rubric_eval.py`.

---

## Принцип ОП_вх

Клиент **звонит** в дилерский центр; на линии **менеджер ОП** (или админ переводит на него); тема — **покупка / подбор** Чери·Тенет (модель, цена, комплектация, тест-драйв, кредит, трейд-ин).

**Не OP_IN:**

- исходящий CRM-перезвон менеджера → обычно `OTHER` или `OP_OUT` (см. анти-кейсы);
- СТО, б/у без ядра ОП, «только перезвоним», менеджеры заняты — `OTHER`.

## Архетипы (поле `archetype` в JSON)

| Архетип | Смысл | Примеры в JSON |
|---------|--------|----------------|
| `direct_manager` | Сразу менеджер ОП, сделка | `op_in_direct_manager` |
| `admin_handoff` | Администратор салона → перевод → менеджер | `transfer_then_manager_op`, `op_in_8846_*`, **`op_in_9350_*`**, `op_in_8783_*` |
| `admin_question_not_repeat` | Вопрос админа «ранее общались?» — **не** follow-up → Прочие | `op_in_9231_*` |
| `active_sales_not_repeat` | «Созванивались» + активная продажа (цена, кредит) — остаётся OP_IN | `op_in_9217_*` |
| `stt_manager_name` | STT искажает фамилию менеджера, клиент звонит по цене | `op_in_kalaev_stt_solaev_8133_style` |
| `anti_not_op_in` | Должно **не** быть OP_IN (контрольные) | исходящие, СТО, серая зона, 9340, 9402 |

## Типичные ложные срабатывания (что ловят кейсы)

1. **«Алло, имя» при переводе** + «меня зовут Андрей» → ошибочный исходящий → Прочие (`9350`, `8846`).
2. **«Смотрели»** внутри «присматриваю» или «смотрели на сайте» → ошибочный repeat-follow-up → Прочие (`9231`).
3. **«Хотел узнать»** у исходящего CRM → Прочие, не OP_IN (`9340`, `9402`).
