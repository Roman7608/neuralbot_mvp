# Цепочки переключения для голосового бота

**Для:** Сергей Солощев (системный администратор Викингов)

При переводе звонка бот передаёт **первый номер** цепочки. АТС обеспечивает обзвон по цепочке: 3 звонка на первый номер → при нет ответе 3 звонка на следующий и т.д.

---

## Цепочки (первый номер — главный)

| Отдел | Первый номер | Полная цепочка |
|-------|--------------|----------------|
| ОП Чери / Тенет / Джетур | **207** | 207 → 208 → 210 → 222 |
| ОП с пробегом | **215** | 215 → 222 → 202 |
| Администратор | **202** | 202 → 222 |
| Слесарный цех / ассистент сервиса | **302** | 302 → 333 → 311 → 222 |
| Кузовной цех | **312** | 312 → 313 → 316 → 222 |
| Отдел запасных частей | **702** | 702 → 703 → 222 |
| Fallback (бот занят) | **202** или **301** | 202 → 222, 301 |
