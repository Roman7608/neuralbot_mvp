# Улучшение первых секунд транскрипции и решение 404 аудио

## Решение через GigaAM (длина первого чанка)

**Реализовано:** параметр `GIGAAM_FIRST_CHUNK_MAX_SEC` — ограничивает длину первого чанка (по умолчанию 6 сек). Первые 3–5 секунд (приветствие) оказываются в отдельном коротком чанке, что улучшает распознавание.

**Переменные окружения:**
- `GIGAAM_FIRST_CHUNK_MAX_SEC=6` — первый чанк до 6 с (по умолчанию)
- `GIGAAM_FIRST_CHUNK_MAX_SEC=8` — попробовать 8 с
- `GIGAAM_FIRST_CHUNK_MAX_SEC=0` — отключить (старое поведение)

## 1. Проблема 404 при загрузке аудио

**Возможные причины:**
- `file_path` в БД указывает на файл, которого нет на диске (другой сервер, удалён, не скопирован)
- Админка в Docker использует другой `BASE_DIR` или volume, файлы лежат на хосте
- Относительный путь резолвится неправильно (например, `storage/calls/...` vs `/app/storage/calls/...`)

**Рекомендуемые действия:**
1. Проверить значение `file_path` для call_id=887 в БД
2. Убедиться, что `BASE_DIR` админки содержит корень, от которого строятся пути
3. Если админка в контейнере — монтировать каталог `storage/calls` в тот же путь
4. Добавить логирование: при 404 писать в лог `call_id`, `file_path`, `resolved_path`, `exists`

## 2. Улучшение распознавания первых 3–5 секунд

В начале звонка содержатся маркеры для классификации (ОП/СТО, менеджер) и оценки. Ошибки STT в этой зоне критичны.

### Пример из call 887

| Ошибка STT        | Вероятно имелось в виду      |
|-------------------|------------------------------|
| Тенцерес          | Центр на Заставной           |
| Слушева           | слушаю Вас                   |
| (Викинги Чери …)  | Викинги Чери Центр на Заставной, Андреева Юлия, слушаю Вас |

---

## 3. Решения

### A. Постобработка (быстрое внедрение)

**Место:** `text_normalization.py`, `analyze_call_quality.py` (DOMAIN_REPLACEMENTS).

Добавить замены для типичных ошибок приветствия:

```python
# text_normalization.py — term_replacements
r"\bтенцерес\b": "Центр на Заставной",
r"\bслушева\b": "слушаю Вас",
r"\bслушаева\b": "слушаю Вас",
r"\bчелюз\s+сервис\b": "Челюз сервис",  # если нужно сохранять
r"\bвикинги\s+чери\s+тенцерес\b": "Викинги Чери Центр на Заставной",
```

**Аналогично в DOMAIN_REPLACEMENTS** (`analyze_call_quality.py`):

```
"тенцерес": "Центр на Заставной",
"слушева": "слушаю Вас",
"викинги чери тенцерес": "Викинги Чери Центр на Заставной",
```

Плюс: не требует изменения пайплайна, сразу улучшает текст.  
Минус: нужно периодически дополнять по новым ошибкам.

---

### B. Двухпроходная транскрипция (более точное распознавание)

Идея: первые 3–5 секунд транскрибировать отдельно с сильным контекстом.

**Алгоритм:**
1. Вырезать первые 5 секунд в отдельный WAV.
2. Транскрибировать их отдельным проходом STT с `initial_prompt` (если движок это поддерживает):

   ```
   Викинги Чери Центр на Заставной, Андреева Юлия, слушаю Вас. Диалог в автосалоне.
   ```

3. Остальной фрагмент — как обычно (основной конвейер GigaAM).
4. Склеить: «исправленное начало» + «остаток».

**Реализация:** добавить функцию `transcribe_with_prompted_start()` в `analyze_call_quality.py`, вызывать её вместо обычной `transcribe_audio_gigaam()` при `USE_PROMPTED_START=1`.

---

### C. Словарь приветствий (whitelist для подсказки контекста)

Движки с поддержкой `initial_prompt` используют его как подсказку контекста.  
Сейчас используется общий:

```python
INITIAL_PROMPT = "Диалог в автоцентре Викинги на Заставной, менеджер и клиент."
```

Рекомендуется добавить варианты приветствий:

```python
GREETING_PROMPTS = [
    "Викинги Чери Центр на Заставной, Андреева Юлия, слушаю Вас.",
    "Викинги Челюз сервис, Андреева Юлия, добрый день.",
    "Менеджер отдела продаж, Викинги, добрый день.",
]
# Выбирать по контексту или склеивать: INITIAL_PROMPT + случайный GREETING_PROMPT
```

Длинные списки могут давать галлюцинации, поэтому лучше 1–2 короткие фразы.

---

### D. Гибридный режим: усиленное начало + GigaAM на остатке

Если аналитика идёт через GigaAM:

1. Первые 5 секунд — отдельный проход STT с `initial_prompt` (при наличии второго конвейера).
2. Остаток — GigaAM.
3. Объединение: `start_stt + gigaam_rest`.

Даёт более стабильное приветствие и скорость GigaAM на длинном фрагменте.
