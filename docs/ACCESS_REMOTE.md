# ACCESS_REMOTE

## Админка с ноутбука

Если ноутбук не находится в одной сети с `server7`, прямой доступ к `http://217.113.123.69:8000` может не работать.

Рабочий способ доступа с ноутбука:

1. Подключить проект в `Cursor` по `SSH` к `server7`.
2. В `Cursor` открыть панель `Ports` / `Forwarded Ports`.
3. Пробросить локально порт `8000` с удалённого `server7`.
4. Открыть на ноутбуке в обычном браузере:

```text
http://127.0.0.1:8000
```

или:

```text
http://localhost:8000
```

Это открывает админку `server7` через SSH-туннель `Cursor`, без внешнего открытия порта `8000`.

## Админка внутри server7

Если работа идёт в браузере внутри `Remmina` на рабочем столе `server7`, используйте:

```text
http://localhost:8000
```
