ПЕРЕЗАПУСК max-bot (после правок .env)
--------------------------------------------------------------------------------

Из каталога проекта:

  cd ~/VikingiAll
  docker compose restart max-bot

Пересборка образа, если менялись зависимости/код:

  cd ~/VikingiAll
  docker compose build max-bot && docker compose up -d max-bot

Через скрипт управления:

  cd ~/VikingiAll
  ./vikingi_manage.sh restart-one max-bot

Логи в реальном времени:

  docker compose logs -f max-bot

--------------------------------------------------------------------------------
chat_id групп MAX (дублирование лидов по отделам)
--------------------------------------------------------------------------------

Значения задаются в .env. Идентификатор виден в адресной строке веб-клиента:
открыть группу → URL вида https://web.max.ru/<число> — это chat_id (часто
отрицательное число).

Переменная              | chat_id (server7, 2026-03) | Группа в MAX
------------------------|----------------------------|----------------------------------
MAX_CHAT_CHERY_TENET    | -72737637400823            | ОП Chery & Tenet
MAX_CHAT_JETOUR         | -72737637400823            | Jetour (тот же чат, что Chery/Tenet)
MAX_CHAT_USED_CARS      | -72737780990199            | ОП Авто с пробегом
MAX_CHAT_SERVICE        | -72737804255479            | Слесарный цех
MAX_CHAT_BODY_REPAIR    | -72737827717367            | Кузовной цех
MAX_CHAT_SPARES         | -72737845870839            | Запасные части
MAX_CHAT_CONSULTANT     | -72737864483063            | Прочие / Администратор

При смене группы в MAX обновите .env и перезапустите max-bot. Токен MAX_BOT_TOKEN
и прочие секреты — только в .env, в этот файл не копировать.

Логика маппинга потребность → чат: max_bot/notify_max_channels.py

--------------------------------------------------------------------------------
Обязательно для работы бота
--------------------------------------------------------------------------------

  MAX_BOT_TOKEN=<из кабинета MAX, business.max.ru → Чат-боты>

Бот должен быть добавлен в каждую группу и иметь право отправлять сообщения.
