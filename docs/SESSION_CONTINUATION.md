# Продолжение сессии — Vikingi

Контекст для продолжения работы после переноса на новый сервер (Ubuntu).

## Что сделано

### Админка
- **Разграничение прав (роли 1–6):**
  - 1: Менеджер ОП — лиды (вчера+сегодня), звонки только ОП, без транскрипции
  - 2: Ассистент СТО — лиды (вчера+сегодня), звонки только СТО, без транскрипции
  - 3: Хостес — только лиды (вчера+сегодня)
  - 4: Руководитель ОП — лиды, звонки ОП, транскрипция, загрузка только ОП
  - 5: Руководитель СТО — лиды, звонки СТО, транскрипция, загрузка только СТО
  - 6: Полный доступ
- **Авторизация:** логин+пароль, сессия в cookie, таблица `admin_users` (PostgreSQL)
- **Вход:** выбор логина из списка + ввод пароля
- **Хеширование паролей:** bcrypt (не passlib)

### Лиды
- Страница `/leads`: разбивка по дням, фильтры (канал, источник), отчёт
- Поле `source` в `telegram_leads`: telegram | phone (телефонный бот)
- Маппинг каналов: ОП Джетур, ОП Тенет, Слесарный цех, авто с пробегом, Кузовной цех, отдел запчастей, прочие

### Миграции БД
- 004: колонка `source` в `telegram_leads`
- 005: таблица `admin_users`

## Архитектура

- **3 процесса:** Telegram-бот, голосовой бот (demo_main), админка (uvicorn)
- **PostgreSQL:** vikingi_analytics, пользователь analytics_user
- **Asterisk:** на внешнем сервере у провайдера

## Планы

1. **Деплой на сервер в Docker** — PostgreSQL, TG-бот, голосовой бот, админка в контейнерах
2. **Асинхронная обработка звонков** — несколько звонков одновременно
3. **Установка LLM, STT, TTS** на сервер
