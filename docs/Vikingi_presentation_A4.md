# Проект «Автодилер» — система автоматизации связи дилерского центра

**Вступление.** Жёсткие условия рынка автобизнеса в 2026 году требуют контроля за лидами, качества работы менеджеров, улучшения клиентского сервиса и при этом — сокращения затрат. Проект «Автодилер» решает эти задачи комплексно. Единая платформа объединяет голосового бота для звонков, Telegram-бота для заявок в мессенджере, автоматическую запись на СТО (по телефону или в чате), аналитику качества разговоров и интеграцию с 1С.

---

## Схема проекта

```
   Входящий звонок (24/7)              Заявка в Telegram (24/7)
            │                                    │
            ▼                                    ▼
   Голосовой бот  ──────────────►  Telegram-бот: лиды в группы отделов
            │                                    │
            └────────── Определение потребности, сбор ФИО и телефона ──────────┘
                                            │
                     ┌──────────────────────┼──────────────────────┐
                     ▼                      ▼                      ▼
              Отдел продаж              СТО / Сервис         Запчасти / Бухгалтерия
                                            │
                     Запись на СТО: по телефону или в мессенджере — без потери лидов
                                            │
                                            ▼
                     Записи звонков → Транскрибация → Аналитика (скрипты, качество) → 1С / Отчёты
```

---

## Возможности

| Компонент | Функции |
|-----------|---------|
| **Голосовой бот** | Приём звонков 24/7, распознавание речи, определение потребности (продажи/сервис/запчасти), сбор ФИО и телефона, запись на СТО по телефону, перевод на нужного специалиста |
| **Telegram-бот** | Приём заявок 24/7, маршрутизация лидов в группы отделов, запись на СТО в мессенджере, сбор и передача контактов, публикация новостей в канал |
| **Аналитика звонков** | Транскрибация записей, оценка по критериям (приветствие, потребности, имя, презентация и др.), контроль соблюдения скриптов импортёра, отчёты по менеджерам и звонкам |
| **Интеграция** | Asterisk, 1С, PostgreSQL, SpRecord (записи с аналоговой АТС) |

## Выгоды

| Выгода | Описание |
|--------|----------|
| **Сокращение ФОТ** | Запись на СТО и квалификация лидов — круглосуточно, без операторов. Можно сократить штат ассистентов сервиса и приемной. |
| **Бонусы импортёра** | Аналитика звонков проверяет соблюдение скриптов общения. Облегчает выполнение требований импортёра и помогает получать бонусы за качество диалогов. |
| **Нет потерянных лидов 24/7** | Голосовой бот и Telegram-бот работают круглосуточно. Каждый обратившийся — в воронке, а не «забытый» в нерабочее время. |
| **Рост воронки продаж** | Больше заявок по авто, сервису и запчастям: лиды не теряются, сразу квалифицируются и попадают в нужный отдел. |
| **Объективная оценка менеджеров** | Транскрипции и оценки по критериям — основа для обучения и KPI. Руководитель видит реальную картину, а не «на слово». |
| **Снижение нагрузки на руководителей** | Аналитика сама выделяет проблемные звонки и формирует отчёты. Меньше ручной проверки — больше времени на управление. |
