## 3. Telegram-бот — что сделали

- **Меню выбора отделов:** при любом текстовом упоминании (например, «крыло от боинга») бот не уходит в опрос по авто, а показывает меню: «Я могу передать Ваш запрос в отдел продаж Chery/Tenet, либо… Какой из этих вариантов Вас интересует?»
- **Кнопки отделов в WAITING_NEED:** при нажатии «Слесарный цех», «Кузовной цех», «Автомобили с пробегом», «Запчасти», «Прочие» — сразу переход в соответствующий сценарий (без повторного показа меню).
- **Запись на ТО только по кнопке:** опрос на ТО запускается только при нажатии «Записаться на ТО». Текстовые фразы про ТО («пройти ТО», «записаться на ТО», «техобслуживание» и т.п.) получают ответ с просьбой нажать кнопку «Записаться на ТО» или «Слесарный цех».
- **Валидация телефона (запись на ТО):** сообщение «Пожалуйста, укажите корректный номер телефона» показывается не более одного раза; при следующих неверных вводах — просьба нажать кнопку «Передать номер телефона».
- Важно: после правок кода бота нужна **пересборка** образа, а не только перезапуск:  
  `docker compose up -d --build telegram-bot`

## 6. Обновление Cursor (Linux)

- Файл обновления: `cursor_2.6.19_amd64.deb` в `~/Загрузки` (на машине пользователя — путь вида `/home/<user>/Загрузки`).

## 7. Тестирование телефонии: номер 707755

- Внешний номер Викинги **707755** настроен на Asterisk проекта (по конфигу: DID 707755 приходит с Инфолады на наш Asterisk, далее — AudioSocket в voice-bot).

**Проверки на сервере (в каталоге проекта `VikingiAll`):**

```bash
cd ~/VikingiAll   # или /home/vikingi/VikingiAll
docker compose exec asterisk asterisk -rx "pjsip show registrations"
docker compose ps asterisk voice-bot
```

- Ожидалось: регистрация `infolada-reg` в статусе **Registered**, контейнеры `asterisk` и `voice-bot` в состоянии **Up (healthy)**. По скриншоту пользователя — так и было.

**Просмотр логов Asterisk при звонке:**

```bash
cd ~/VikingiAll
docker compose logs -f asterisk
```

- Команды нужно выполнять из каталога, где лежит `docker-compose.yml`, иначе ошибка «no configuration file provided: not found». На сервере — не с «Рабочего стола», а из `~/VikingiAll` (или где развёрнут проект).

## 8. Контрольный звонок на 707755 — нет гудков

- С двух разных телефонов набирали 707755 — **набор не происходит, нет тональных гудков**.
- Вывод: вызов до Asterisk проекта не доходит; проблема на стороне провайдера или формата набора.

**Рекомендации:**

1. **Уточнить у Инфолады:**
   - полный формат набора номера (с городского и с мобильного): например, 8-XXX-707-75-55, +7…, код города;
   - активирован ли DID 707755 и привязан ли он к SIP-регистрации Vikingi (vikingi-ai);
   - нет ли ограничений по операторам/регионам.
2. Набирать номер **строго в том формате**, который укажет провайдер.
3. Со стороны проекта Asterisk и voice-bot готовы принять звонок (регистрация есть, контейнеры работают).
